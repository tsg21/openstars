Creation of a race

Creating a race occurs as a result of several steps, each of which is a separate menu with settings:

Step 1

At any time during the creation of a race, “Advantage Points Left” is indicated in the upper right corner. These are the points that remain after creating a race. Ultimately they must be expressed as a non-negative number.

In the first step, select:

Race Name

Race name. This is the common name for your race.

Each of the standard races has fixed characteristics.

Pay attention to the Stars bug! Race File Corruption.

Plural Race Name

Plural name for representatives of a race. That is, if the race name is “Humanity”, then this field will be called “People”.

Password

Race password. When playing a multiplayer game, it is highly advisable to fill out. In this case, this password will be the password for your move file.

Predefined Races

Selecting an existing race. The first 6 are the standard races in the game. “Random” - at the start you will be given one of the standard races (pay attention to the Stars bug! “Random Race”). Custom - the ability for you to personally manage all the race settings - create a race for yourself.

Spend up to 50 leftover advantage points on

The ability to transfer the remaining points into one of the starting bonuses (but not more than 50 points), which changes the home planet:

Surface Minerals

Obtaining ready-made minerals on the surface of the starting planet: 10 kt of the rarest minerals for each unused point, for example, if you have 20 points, you will receive 200 kt of the rarest mineral.

Mineral concentrations

The increase in mineral concentration increases by 1% for the rarest mineral for every 3 unused points.

Mines

Receive one additional mine for every 2 unused points.

Factories

Receive one additional factory for every 5 unused points.

Defenses

Receive one additional defense station for every 10 unused points.

Icon

Changing the icon symbolizing the race in the game. In a party, all races must have different icons, and in the event of a conflict, Stars! will automatically change the images of one of the conflicting ones. If you want your own, then it is better to agree on this in advance, at the level of creating the rules of the game.

Step 3

We choose LRT. Each of the properties can be either selected or cleared:

Step 4

We choose a hub - natural living conditions where a race can exist.

Each of the parameters of gravity, temperature or radiation can be in a state of immunity or some kind of favorable range for life. If immunity is selected, then nothing else can be changed in this category. If a range is selected, it can be varied in width and position position.

In addition, at this step, a parameter such as “Growth Rate” is selected. It determines how quickly a race reproduces under ideal conditions. And accordingly, the larger it is, the faster representatives of the race reproduce in conditions suitable for life.

While setting up Stars! determines what average number of planets will be available for settlement. In this case, on average, one out of seven planets will be suitable for life (this does not take into account terraforming).

Step 5

Selection of economic parameters:

Here, a choice is made of the characteristics of the race that determine the economic development of the race, that is, how much the race can be developed and how quickly this can be done.

The choice is as follows:

One resource is generated each year for every N colonists.

It is set how many resources the colonists themselves will generate, that is, N colonists will generate 1 resource. The parameter varies from 700 to 2500.

Every 10 factories produce N resources each year.

It is specified how many resources 10 factories will produce in 1 year. That is, 1 factory will generate N/10 resources on average. The parameter varies from 5 to 15.

Factories require N resources to build.

It sets how many resources are needed to build one factory. This parameter sets the speed of building factories and can take values from 5 to 25.

Every 10,000 colonists may operate up to N factories.

Sets how many factories colonists can manage. In fact, it sets the upper ceiling for the development of your factories - the higher this parameter, the more factories you can potentially build. The parameter can vary from 5 to 25.

Factories cost 1 kt less of Germanium to build

Can be selected or cleared. If discarded, then building a factory builds 4 kt Ger, if selected, then 3 kt.

Every 10 mines produce up to N kt of each mineral every year.

It is set how many minerals the mine will produce in 1 year. That is, 1 mine will on average produce N/10 minerals of each type. The parameter varies from 5 to 25.

Mines require N resources to build.

It sets how many resources are needed to build one mine. This parameter sets the speed of mine construction and can take values from 2 to 15.

Every 10,000 colonists may operate up to N mines.

It sets how many mines colonists can manage. In fact, it sets the upper limit for the development of your mines - the higher this parameter, the more mines you can potentially build. The parameter can vary from 5 to 25.

Step 6

Selecting scientific parameters:

This step is the last and it determines the cost characteristics of the sciences and the possibility of a starting bonus. In total, there are 6 areas of technology development, each of which can be placed in one of the following positions:

Costs 75% extra

The development of this science will cost 1.75 times more.

Costs standard amount

Standard cost of science.

Costs 50% less

Science will be 2 times cheaper.

In addition to all this, you can select the item “All 'Costs 75% extra' research fields start at Tech 3” (or ...Tech 4 if you chose JOAT). If this point is rejected, the start occurs with the standard level of technology development specified by the previous steps. If you select this item, then all technologies that were selected above as “Costs 75% extra” start at least from the 3rd (or 4th, if JOAT) level. If the level has already been completed (for example, level 5 Elec when choosing SS), then the item in this branch does not give anything.

After setting the necessary parameters in the steps of creating a race, you can click the “Finish” button. Next they will offer to save the race. This will be a separate file “*.r?” and race can be used.
