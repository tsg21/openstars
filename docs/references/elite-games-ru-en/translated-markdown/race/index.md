Races

Races represent the different playing factions (nations). Each race has a lot of parameters that determine where and how representatives of the race can live, what they can build, how quickly to study various sciences, the ability to build planetary buildings, etc. Each player has the opportunity to make a race “for themselves.” It is not possible to create any race; it is necessary to maintain a balance of parameters, which is reflected in the Advantage Points Left indicator. These are points that can be invested in the race. Accordingly, if it is positive (>0), then this means that the race can be improved by contributing points to something useful. If it is negative, it means that too many goodies have been collected and it will not be possible to create a race in this form - you need to remove something useful or take a negative property.

To play, you must “collect” your race in advance or choose one of the existing ones. Race creation occurs when you select “Customize Race...” when starting the game, when editing a race file, or when launching “Custom Race Wizard...” in the game’s “File” menu.
