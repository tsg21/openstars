Description

Destroyer
The very first ship whose direct purpose was combat operations. Quite cheap to produce, has a minimal set of weapons. The only drawback is the lack of a shield slot. After mastering the “Cruiser” design, it is used only when performing indirect combat missions.

Cruiser
Strengthened "Destroyer" by approximately half. But at the same time it has better armor, initiative, and more effective expansion slots (to improve combat characteristics). Used exclusively as a combat strike or auxiliary ship. For non-IT and non-SS races, the topmost ship is when creating a missile fleet capable of passing through gates. In this class of tasks, only Rogue and Nubian compete with it.

Battle Cruiser
The most powerful escort warship. Available only to the WM race. Highly effective in the mid-game and used as an attack ship.
