Description

Colony Ship
Base ship for colonization. Used by all races except HE. Cheap to produce and able to create a minimal colony. It is unacceptable for the transportation of goods, as well as for other possible purposes.

Mini Colony Ship
Basic colonization ship for HE races. Cheapest to produce and able to create a minimal colony. When creating a ship, it is optimal to use the Settler's Delight engine - this is a unique engine for HE that can only be used in this hull.
