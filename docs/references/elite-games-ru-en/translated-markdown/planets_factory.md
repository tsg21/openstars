Factories

Factories are stationary planetary buildings that increase the productivity of the colony of the planet on which they are built.

To build a factory, you need to spend a certain amount of resources and minerals. Once built, the factory is ready for operation - next year, if it is controlled by colonists, it will bring additional resources in accordance with the race that controls the factory.

If colonists leave the planet, the factories remain intact.

It is impossible to build more factories than you can theoretically control given the current climate of the planet. If for some reason the number of factories exceeds this limit (capture of an alien planet, climate change), then the factories will not disappear anywhere, there will simply be more of them than the limit.
