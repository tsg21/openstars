# Appendix A. Keyboard Shortcuts

## General

| Press | Action |
| --- | --- |
| `F1` | Open the online help. |
| `F2` | Open the Technology Browser. |
| `F3` | Cycle through reports: `Planet Summary Report`, `Fleet Summary Report`, `Other's Fleet Summary Report`, `Battle Report`, then close the report window. |
| `F4` | Open the Ship Design dialog. |
| `F5` | Open the Research dialog. |
| `F6` | Open the Battle Plans dialog. |
| `F7` | Open the Player Relations dialog. |
| `F8` | Open the View Race dialog. |
| `F9` | Generate a new turn immediately. |
| `F10` | Display your score. |
| `1`, `2`, `3`, `4`, `5`, `6` | Change the Scanner view: `Normal` (`1`), `Surface Mineral` (`2`), `Mineral Concentration` (`3`), `Planet Value` (`4`), `Population` (`5`), `No Player Info` (`6`). |
| `7`, `8`, `9`, `0`, `Shift-0` | Toggle Scanner overlays: `Radar Coverage` (`7`), `Mine Fields` (`8`), `Fleet Paths` (`9`), `Planet Names` (`0`), `Ship Count` (`Shift-0`). |
| `Esc` | Close the displayed report. |
| `Ctrl-F` | Find a planet or fleet in the Scanner. |
| `+` / `-` | Zoom in or out in the Scanner. |
| `Up Arrow` / `Down Arrow` | Display the previous or next message. |
| `Home` / `End` | Display the first or last message in the Messages pane. |
| `Enter` | Go from the Messages pane to the related dialog or location. |
| `Backspace` / `Delete` | Delete the selected waypoint. |
| `P` / `N` | Display the previous or next planet or fleet in the Command pane. |
| `[` / `]` | Display the previous or next planet with a starbase in the Command pane. |
| `Q` | Find the previous or next fleet owned by another player. Requires the `Other's Fleet Report` to be open. |
| `V` | Open the Production dialog. |
| `F` | Find your location in the Scanner pane. |
| `,` | Display your fleet or planet with the lowest ID number in the Command pane. If the fleet is already selected, the planet is displayed, and vice versa. |
| `.` | Decrease the selected fleet's warp speed to the current waypoint by one. |
| `/` | Increase the selected fleet's warp speed to the current waypoint by one. |
